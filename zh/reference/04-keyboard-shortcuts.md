## 概述

GenAura 的快捷键分布在多个功能区域，包括 macOS 应用菜单、对话输入框、内嵌浏览器、对话框、工作区面板等。本篇按区域整理**当前版本中真实存在**的快捷键，所有组合键均区分 macOS（⌘ Cmd）与 Windows（Ctrl）。

> 说明：GenAura 在 Windows / Linux 平台**不显示应用菜单栏**，因此 macOS 应用菜单相关快捷键**仅 macOS 可用**。文本编辑的剪切 / 复制 / 粘贴（Ctrl\+X / C / V）在所有平台上仍可使用系统默认快捷键。

## 全局快捷键（仅 macOS）

以下快捷键通过 macOS 应用菜单提供，Windows / Linux 平台不显示菜单栏。

### 应用菜单

| 组合键 | 作用 |
| --- | --- |
| ⌘Q | 退出 GenAura |
| ⌘H | 隐藏 GenAura 窗口 |
| ⌘Alt\+H | 隐藏其他应用窗口 |

> macOS 应用菜单中还提供"显示全部"菜单项（用于显示所有被隐藏的窗口），无固定快捷键，可通过菜单栏点击触发。

### 编辑菜单

| 组合键 | 作用 |
| --- | --- |
| ⌘Z | 撤销 |
| ⌘Shift\+Z | 重做 |
| ⌘X | 剪切 |
| ⌘C | 复制 |
| ⌘V | 粘贴 |
| ⌘A | 全选 |

### 视图菜单

| 组合键 | 作用 |
| --- | --- |
| ⌘0 | 重置窗口缩放至 100% |
| ⌘=（⌘加号） | 放大窗口内容 |
| ⌘-（⌘减号） | 缩小窗口内容 |
| ⌘Ctrl\+F | 切换全屏模式 |

### 窗口菜单

| 组合键 | 作用 |
| --- | --- |
| ⌘M | 最小化窗口 |
| ⌘W | 关闭窗口 |

## 对话区快捷键

### 消息输入框

| 组合键 | 作用 | 适用区域 |
| --- | --- | --- |
| Enter | 发送当前消息（`@` 或 `/` 弹窗未激活时） | 对话输入框 |
| Shift\+Enter | 插入换行 | 对话输入框 |
| Enter | `@` 引用弹窗激活时：选中当前高亮项（快捷选项或知识库条目） | 对话输入框（`@` 弹窗） |
| Enter | `/` 指令弹窗激活时：选中当前高亮指令并填入 | 对话输入框（`/` 弹窗） |
| ↑ / ↓ | `@` 或 `/` 弹窗激活时：上下移动高亮项 | 对话输入框（弹窗激活时） |
| Esc | `@` 或 `/` 弹窗激活时：关闭弹窗（保留已输入文本） | 对话输入框（弹窗激活时） |

> 弹窗未激活时，`↑` / `↓` / `Esc` 不被对话输入框拦截，沿用编辑器默认行为（光标移动等）。

### 对话标题重命名

点击对话顶部标题进入编辑态后生效：

| 组合键 | 作用 | 适用区域 |
| --- | --- | --- |
| Enter | 保存新标题 | 对话标题编辑框 |
| Esc | 取消编辑，恢复原标题 | 对话标题编辑框 |

### 左侧导航对话重命名

在对话列表中对某对话触发"重命名"进入行内编辑态后生效：

| 组合键 | 作用 | 适用区域 |
| --- | --- | --- |
| Enter | 保存新对话名 | 左侧导航对话编辑框 |
| Esc | 取消编辑 | 左侧导航对话编辑框 |

## 内嵌浏览器快捷键

> 浏览器 Tab 在不同状态下键盘行为不同：
>
> - **AI Agent 控制中**：拦截所有键盘事件，防止用户抢占
> - **用户已接管**：仅拦截下方列出的快捷键，其余放行至网页

| 组合键 | 作用 | 适用区域 |
| --- | --- | --- |
| Esc | 退出接管，释放对浏览器的控制权 | 浏览器 Tab（接管状态） |
| ⌘K（macOS）/ Ctrl\+K（Windows） | 拦截浏览器内搜索快捷键，避免触发应用搜索或被网页拦截 | 浏览器 Tab（接管状态） |
| Enter | 在地址栏提交并导航到输入的 URL | 浏览器 Tab 地址栏 |

## 工作区面板宽度调整

工作区左右两侧各有一个面板分隔条。先用 `Tab` 键将焦点移到分隔条上，再按方向键调整宽度：

| 组合键 | 作用 | 适用区域 |
| --- | --- | --- |
| → | 左侧分隔条：缩窄左栏；右侧分隔条：缩窄右栏 | 工作区分隔条（聚焦后） |
| ← | 左侧分隔条：增宽左栏；右侧分隔条：增宽右栏 | 工作区分隔条（聚焦后） |
| Shift\+→ / Shift\+← | 同上，但步长更大（默认步长 16px，按 Shift 后为 64px） | 工作区分隔条（聚焦后） |

> 左侧分隔条在拖动到极窄时会自动折叠左栏。

## 表单输入通用快捷键

以下快捷键分布在多个表单组件中，行为模式一致（Enter 提交 / Esc 取消 / Backspace 删除末尾项），集中列出便于查阅。

### 标签输入

适用于品牌配置中的标签输入框（如关键词、别名）：

| 组合键 | 作用 | 适用区域 |
| --- | --- | --- |
| Enter / `,` / `，` | 提交当前输入为标签 | 品牌配置 - 标签输入 |
| Backspace（输入框为空时） | 删除最后一个已添加标签 | 品牌配置 - 标签输入 |

### URL 输入

适用于创建品牌时的官网链接输入：

| 组合键 | 作用 | 适用区域 |
| --- | --- | --- |
| Enter / Space / `,` | 提交当前输入为官网 URL | 创建品牌 - 链接输入 |
| Backspace（输入框为空时） | 删除最后一个已添加 URL | 创建品牌 - 链接输入 |

### 行内编辑

适用于问题矩阵、知识库树节点重命名、发布记录 URL 添加等场景：

| 组合键 | 作用 | 适用区域 |
| --- | --- | --- |
| Enter | 保存当前内容 | 问题矩阵 - 行内编辑 |
| Esc | 取消编辑 | 问题矩阵 - 行内编辑 |
| Enter | 提交节点重命名 | 知识库 - 树节点重命名 |
| Esc | 取消节点重命名（新建节点时取消创建） | 知识库 - 树节点重命名 |
| Enter | 触发 URL 导入 | 知识库 - 导入对话框 URL 输入 |
| Enter | 提交新增发布记录 URL | 发布记录 - 添加 URL |
| Esc | 取消新增发布记录 URL | 发布记录 - 添加 URL |

## 常见问题

### Q1：在 Windows 上为什么没有应用菜单栏？

GenAura 在 Windows / Linux 平台不显示菜单栏。因此 macOS 应用菜单中的"撤销 / 重做 / 剪切 / 复制 / 粘贴 / 全选 / 缩放 / 全屏"等快捷键在 Windows 上**不通过应用菜单提供**；但文本编辑的剪切 / 复制 / 粘贴（Ctrl\+X / C / V）仍可由系统默认行为处理。如需最大化窗口，请使用系统自带的最大化按钮或 Win\+↑。

### Q2：为什么 F5 / F12 / ⌘R 在正式版中不生效？

正式版中，刷新窗口、强制重新加载、开发者工具等快捷键已被禁用，避免误触导致会话中断。这些快捷键仅在开发或测试版本中可用。

### Q3：在对话输入框按 Enter 直接发送了，如何换行？

按 **Shift\+Enter** 可插入换行。单独按 Enter 在弹窗未激活时即为发送消息。

### Q4：`@` 引用弹窗或 `/` 指令弹窗激活时，Enter 选了项却没有发送，正常吗？

正常。当 `@` 或 `/` 弹窗激活时，Enter 用于**选中当前高亮项**，不会发送消息。需先关闭弹窗（按 Esc 或选择一项后弹窗自动关闭）后再按 Enter 发送。

### Q5：在浏览器 Tab 接管状态下，为什么 ⌘K / Ctrl\+K 没有反应？

用户接管浏览器时，应用会拦截 ⌘K / Ctrl\+K，目的是防止该快捷键触发应用层搜索或被网页内页面拦截。这是预期行为，并非故障。

### Q6：编辑器中按 ⌘S / Ctrl\+S 为什么没有保存？

统一文件编辑器未注册自定义保存快捷键。如需保存编辑结果，请使用编辑器界面上的保存按钮，详见 [文件编辑器](/how-to/09-file-editor)。

### Q7：如何调整左右两栏面板的宽度？

有两种方式：

- **鼠标拖动**：直接拖动左右两侧的面板分隔条
- **键盘调整**：先用 Tab 键将焦点移到分隔条上，再按 `←` / `→` 调整宽度；按住 Shift 可大步调整
